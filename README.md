## 📌 Featured projects

### 🛠️ EasyTravel — Application Support Lab

A personal application support laboratory focused on monitoring, incident investigation and technical documentation.

This project explores application support methodologies such as metrics analysis, log investigation, root-cause analysis and incident management.

**Focus:** application support, observability, troubleshooting and technical documentation.

➡️ [View the repository](https://github.com/bouboudev/easytravel-application-support-lab)

---

### 🥊 Boxing Legends API

A REST API dedicated to legendary boxers and boxing history.

The project includes business logic for ranking boxers according to several criteria, such as wins, win rate, knockouts, world titles and championships in multiple weight divisions.

**Focus:** REST API design, business logic, data management and backend development.

➡️ [View the repository](https://github.com/bouboudev/boxing-legends-api)

---

### 🧾 Rent Receipt Generator

A web application for generating rent receipts from landlord, tenant and property information.

The application provides a clear interface, automatic calculations, live preview and PDF export.

**Focus:** form handling, automation, document generation and user experience.

➡️ [View the repository](https://github.com/bouboudev/quittance-loyer)

---

### 🎨 Vue Design System

An early design system project built with Vue.js.

This project explores reusable UI components, visual consistency and scalable frontend architecture. It also reflects my professional interest in design systems and component-based development.

**Focus:** reusable components, UI consistency, component architecture and frontend scalability.

➡️ [View the repository](https://github.com/bouboudev/design-system-vue)
